# 扩展版验收记录

日期：2026-10-15。环境：Linux 云端，Godot 4.6.3 标准版，GL Compatibility 项目。以下为实际主场景和脚本执行结果，所有写入用户数据的测试均使用独立临时目录。

## 已完成的功能

- 六张内置地图：原有三关及熔脉岔口、霜镜交汇、裂隙围城；含双门、双线、四入口轮换、真实熔岩伤害和霜场减速
- 六种防御塔的真实 3D 模型缩略图；紧凑 608×70 塔栏，按需建造／升级／出售面板与资料库
- 滚轮缩放、中键或 Shift 拖动、单指平移、双指捏合、镜头复位与 HUD／模态界面隔离
- 本地 15×9 关卡设计器：正交路径、撤回／擦除、4–24 基座、1–12 波、8–40 敌人／波、100–2000 初始金币、保存／载入／试打
- 固定 60Hz 的作者操作记录；通关后在新场景中按真实规则重放并核对最终状态，验证通过才显示“已验证”
- 手动 GitHub Actions 配置：iOS 未签名打包及 macOS Intel／Apple Silicon 通用 .app ZIP。由用户自行运行

## 回放验证边界

- “已验证”只意味着当前关卡、当前游戏规则下，已保存的合法操作能在隔离场景中重现真实胜利与最终状态
- 关卡编辑、规则变化、操作篡改、金币不足、冷却绕过或非法重复开波不通过
- 文件中的 verified=true 不能直接建立可信标记；重新启动应用后需要重新执行保存的回放
- 这是本地可重复性核验，不是联网身份认证、服务端反作弊或云端发布系统
- 伤害数字等外观效果使用独立的随机来源，不消耗战斗重放的 RNG
