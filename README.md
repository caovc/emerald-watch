# 翡翠哨站 · Emerald Watch V2

一个可直接运行的 Godot 4 三维塔防游戏原型。漂浮岛屿、低多边形建筑、虫群和战斗特效由代码生成；包含 **6 种防御塔、7 类敌人、3 张地图，每关 8 波**，以及原创循环音乐和战斗音效。无需外部模型、插件或联网服务。

## 快速开始（包括 Mac）

1. 安装官方 **Godot 4.6.3 标准版**，不需要 .NET 版：[Godot 官网](https://godotengine.org/)
2. 解压完整工程文件夹，不要只取出 `project.godot`
3. 在 Godot 项目管理器点击 **Import / 导入**，选择 `project.godot`
4. 等待字体与音频导入完成，按 **F5 / Run Project**。Mac 的功能键如用于系统控制，请按 **Fn + F5**，或点击编辑器右上角播放按钮
5. 点击底部塔型，再点击地图上带 **+** 的空基座；在选中位置的信息面板点击 **在此建造**
6. 部署完成后点击顶部 **开始第 1 波**

基准画布为 1440 × 900，推荐 16:10 窗口。使用 GL Compatibility 渲染器。核心操作都有可点击的界面按钮，触屏可通过点按完成，不依赖鼠标悬停；桌面版另有快捷键。iOS 实机触控、屏幕安全区和性能仍待验证。

## V2 战场与界面

- 紧凑顶部状态栏：关卡、金币、核心生命、波次、暂停、速度、下一波、设置和资料库入口
- 底部横排六种塔卡；选中基座或塔后才显示建造、升级、出售面板，减少常驻界面对战场的遮挡
- 点击已建防御塔可查看当前数据、升级前后伤害与射程、升级价格及出售返还
- 点击场上敌人可查看实时生命、剩余护盾、减速与灼烧状态，以及克制提示
- 基座支持部署模型预览、射程圈和金币不足提示；鼠标悬停只是额外预览方式，不是操作前提
- **按需资料库**：集中查看六类塔的三级属性、升级成本和克制关系，以及七类敌人的当前关卡／波次生命、速度、护甲、护盾和能力；打开时暂停，关闭后恢复之前的暂停状态

## 关卡与胜负

守护终点的翡翠核心。每关击退全部 **8 波**即获胜；核心初始生命为 **20**。普通敌人漏过扣 1 点，巨型母虫漏过扣 5 点，生命归零失败。

| 关卡 | 初始金币 | 路线与机制 |
|---|---:|---|
| 翡翠哨站 | 360 G | 绵长蛇形路线，适合熟悉塔型配合 |
| 赤岩回廊 | 420 G | 螺旋双门，额外护盾虫；可切换后续敌人的入口 |
| 霜岭裂隙 | 500 G | 双入口交汇，新敌人交替从两路进入，混合疾行与重甲压力 |

- 击杀获得金币；非最终波结束后获得 `35 + 当前波数 × 8` 金币补给
- 波与波之间不自动开战，可以规划建设；战斗中也可建造、升级和出售
- 每座塔最多 3 级；每次升级伤害乘 1.65、射程增加 0.45，攻击间隔也会缩短
- 出售返还该塔累计投入金币的 70%，向下取整
- 关卡按钮可选择地图；结算后可重新挑战、换关或继续下一关
- 重新挑战会重置该局金币、生命、塔与波次，但保留已保存的设置偏好

## 六种防御塔

下表为 1 级基础数据。实际伤害还受重甲、护盾和持续效果影响。

| 塔型 | 价格 | 伤害 | 射程 | 攻击间隔 | 用途 |
|---|---:|---:|---:|---:|---|
| 脉冲箭塔 | 80 G | 24 | 4.6 | 0.65 秒 | 高频单体，经济地处理侦察虫与疾行虫 |
| 熔核炮塔 | 120 G | 38 | 4.0 | 1.65 秒 | 1.6 单位范围爆炸，清理密集虫群和分裂小虫 |
| 霜晶棱塔 | 100 G | 10 | 4.4 | 0.80 秒 | 普通敌人减速 50%，为其他塔争取输出时间 |
| 雷链线圈 | 140 G | 27 | 4.5 | 1.05 秒 | 最多命中 3 个目标，后续弹射伤害为基础值的 85%；对护盾伤害翻倍 |
| 穿甲轨炮 | 150 G | 100 | 6.2 | 2.30 秒 | 无视重甲减伤，优先攻击射程内的重甲虫和巨型母虫 |
| 焰息熔炉 | 130 G | 17 | 3.6 | 0.85 秒 | 范围命中并施加 3 秒灼烧；每秒持续伤害为 `16 × 塔等级`，阻止治疗 |

## 七类敌人与真实克制

这些差异会参与战斗计算，并非只改变模型或文字：

| 敌人 | 机制 | 应对方式 |
|---|---|---|
| 侦察虫 | 常规移动与生命 | 脉冲箭塔负责稳定清理 |
| 疾行虫 | 更快移动、较低生命 | 霜晶减速配合高频攻击 |
| 重甲虫 | 普通伤害降低 55% | 穿甲轨炮和焰息伤害绕过重甲减伤 |
| 巨型母虫 | 高生命；仅受到 25% 减速；漏过扣 5 点核心生命 | 升级轨炮并配合全场技能集火 |
| 护盾虫 | 额外护盾为自身最大生命的 65%，先吸收伤害 | 雷链对护盾造成双倍伤害；破盾后仍需削减生命 |
| 再生虫 | 每秒为 2.8 单位内的自己及队友恢复各自最大生命的 6% | 灼烧中的再生虫不能施放治疗，灼烧目标也不能接受治疗 |
| 分裂虫 | 被击败后生成两只半生命的小型疾行虫，沿死亡位置的路线继续前进 | 熔核范围攻击清理分裂后的目标 |

后期敌人生命随波次增长，不宜只建初始防线而停止投入。穿甲绕过的是重甲减伤，护盾仍会吸收相应伤害。

## 主动技能与入口切换

- **核心震荡 / Q**：仅在战斗波次中可用，对场上所有存活敌人造成 `90 + 当前波数 × 8` 的穿甲伤害，并施加 3 秒减速；冷却 **35 秒**。母虫仍保留其减速抗性
- **切换入口 / E**：仅第二关可用，在北门和南门之间切换，冷却 **12 秒**。只改变之后生成敌人的入场路线；已经上场的敌人继续走原路线
- 第三关自动交替从两路生成敌人，没有手动切门按钮
- 两种操作都有可点击按钮和冷却提示；冷却按战斗模拟时间计算，暂停时停止，2× 速度下相应加快

## 操作

| 鼠标 / 触屏按钮 | 桌面快捷键 | 功能 |
|---|---|---|
| 底部六种塔卡 | 1–6 | 选择塔型 |
| 点击空基座、已有塔或敌人 | — | 查看对应信息；建造仍需确认点击建造按钮 |
| 选中塔后的升级按钮 | U | 升级当前塔 |
| 开始下一波 | 空格 | 进入下一波 |
| 暂停 / 继续 | P | 暂停或继续模拟 |
| 1× / 2× | — | 切换战斗速度 |
| 核心震荡 | Q | 施放全场穿甲减速技能 |
| 第二关切换入口 | E | 切换后续敌人的入口 |
| 设置 | O | 打开设置 |
| 面板关闭按钮 / 点击空地 | 右键 / Esc | 取消战场选择；Esc 也可关闭打开的菜单 |
| 设置中的全部静音 | M | 静音 / 恢复声音；持久音量偏好请在设置中调整 |
| — | F12 | 保存游戏截图 |

F12 将截图写入工程的 `screenshots/emerald-watch.png`，再次截图会覆盖同名文件。导出的应用若没有工程目录写入权限，截图保存可能失败。

## 设置与声音

设置即时生效，并写入 `user://settings.cfg`，下次启动会加载：

- 背景音乐和战斗音效独立音量滑块，以及保留两项音量的全部静音开关
- 全屏 / 窗口切换
- 高 / 低画质：高画质使用 4× MSAA 和方向光动态阴影；低画质关闭两者
- 帧率上限：30 / 60 / 120 FPS / 无限制；这是上限，实际帧率仍取决于设备与显示系统
- 镜头距离：18–28，默认 22.8；数值越小，视角越近
- 射程圈和伤害数字分别开关
- 恢复默认设置及操作提示

打开设置会暂停战斗，关闭后恢复进入设置前的暂停状态。桌面窗口选项在无窗口测试环境中会安全跳过；移动平台的实际效果仍待验证。设置持久化不等同于战局存档：当前不保存进行中的关卡进度。

音频包括一首 **90 BPM、约 42.67 秒无缝循环的原创电子氛围曲**，以及 **14 种原创合成音效**，覆盖建造、升级、六种攻击、命中、漏怪、波次、胜负和出售。使用独立音乐 / 音效总线、音效并发限制与限幅，控制密集战斗中的混音；暂停不会重新开始整首音乐。没有下载的录音、第三方采样或现成旋律。见 [音频说明](assets/audio/README.md)。

已在 **Linux 云端、Godot 4.6.3** 运行工程并进行图形运行和无窗口自动化检查。V2 的完整关卡、UI、音频与平台验收仍需分别验证，不能把语法通过当作所有平台均已通过。

**macOS、Windows 和 iOS 尚未在本地实机测试。** Mac 可按上文导入同一份源码工程；这不代表已经验证 macOS 独立应用、签名或公证。iOS 的触控布局、设备性能、签名安装仍待实测。

**GitHub Actions 的未签名 iOS / IPA 导出流程正在准备，远程构建运行与产物验证尚待完成。当前不能据此认定已经获得成功构建的 IPA。** 即使后续生成未签名 IPA，它也不是可直接安装的已签名 App，仍需用户按自己的设备和分发方式处理合法签名与安装。

在工程目录执行；Godot 可执行文件的命令名依安装方式而异：

```sh
# 实际主场景与战斗机制测试
godot --headless --path . --script res://tests/integration.gd

# 设置模块：25 项隔离检查，使用临时目录避免改写自己的设置
SETTINGS_TEST_HOME="$(mktemp -d)"
HOME="$SETTINGS_TEST_HOME" XDG_DATA_HOME="$SETTINGS_TEST_HOME/data" \
  XDG_CACHE_HOME="$SETTINGS_TEST_HOME/cache" \
  godot --headless --path . --script res://tests/settings_smoke.gd

# 原创音频素材检查；仅重新生成 / 检查素材时需要 Python 3 与 NumPy
python assets/audio/generate_audio.py --check
```

设置检查覆盖开关菜单、原暂停状态恢复、重复调用、实际属性应用、保存与重新加载、恢复默认、非法配置处理，以及地图重建后的设置应用。音频无窗口检查不能替代实际试听；普通玩家直接运行已打包的 WAV 文件，无需 Python。

## 文件结构

- `project.godot`、`main.tscn`：工程配置与启动场景
- `scripts/main.gd`：地图、程序化模型、敌人、战斗、关卡和输入逻辑
- `scripts/game_ui.gd`：紧凑 HUD、选择面板、关卡选择与结算界面
- `scripts/game_settings.gd`：真实设置界面、即时应用与本地保存
- `scripts/game_audio.gd`：循环音乐、音效播放和混音控制
- `assets/audio/`：原创音频、生成脚本、清单及音频说明
- `assets/ui-font.otf`、`assets/FONT-LICENSE.txt`：中文字体与对应许可
- `assets/icon.svg`：工程图标
- `tests/`：主场景与模块自动化测试
- `screenshots/`：运行截图

## 修改与扩展

- 塔型基础参数：`scripts/main.gd` 中的 `TOWER_DATA`
- 三关路线、入口和基座：`configure_level()`、`ROUTE`、`routes`、`PAD_CELLS`
- 敌人生命、奖励、护甲与状态：`spawn_enemy()`、`damage_enemy()`、`game_tick()`、`enemy_stats()`
- 技能与切门：`use_ability()`、`toggle_gate()`
- 总波数：`TOTAL_WAVES`；修改后同步波次提示、母虫出现条件和自动化测试
- UI、设置、音频各自位于独立脚本；新增中文文字时请检查打包字体的字形覆盖
- 程序化地图与塔模型可逐步替换成自行制作的 `.glb` 资源

当前没有联网、成就或战局存档。设置偏好可保存；第三方商店发布、平台签名及独立安装包验证不属于已经完成的功能。
